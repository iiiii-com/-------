# 中国法律可视化地图

把我国法律体系做成"看得懂、查得到、可核验"的可视化分卷站点：**总览 + 16 个分卷 + 学习方法卷**，每条条文配「原文 → 大白话 → 生活场景 → 常见误区」四段式解读，并附官方原文链接与实用计算器。

面向两类人：**普通人**（快速搞懂与自己相关的法律）和**想系统高效学法的人**（用骨架 + 分卷建立体系）。

## 分卷导航

- **总览** `index.html` — 三大骨架（效力金字塔 / 七大部门法 / 公私法与实体程序法）+ 全部分卷入口
- **部门法**：宪法 `constitution` · 民法典 `civil` · 刑法·犯罪 `criminal` · 消费·借贷·房产 `consumer` · 劳动维权 `labor` · 行政法 `admin` · 程序法 `procedure` · 交通·治安 `traffic` · 医疗与人身损害 `medical`
- **专题**：公司·商事 `company` · 婚姻家庭与继承 `family` · 网络·数据·个人信息 `cyber` · 合同与交易 `contract` · 金融与保险消费 `finance` · 特殊群体与救助 `special` · 税收与发票 `tax` · 房产与物业 `housing`
- **方法**：如何高效学法 `study`
- **全站索引** `all.html` — 跨 19 卷汇总全部条文精讲，支持关键词搜索

## 本地查看

纯静态站点，无需构建。直接用浏览器打开 `index.html` 即可；或起一个本地服务：

```bash
python -m http.server 8000
# 再访问 http://localhost:8000
```

## 数据来源与免责声明

法条均以**国家法律法规数据库**（全国人民代表大会常务委员会办公厅主办，<https://flk.npc.gov.cn/>）的**现行有效文本**为准；每页底部「§附录 法律依据与原文核验」列出所引法律的公布/施行日期与官方原文直达链接。

本图谱为普法学习与可视化整理，**不构成法律意见**；法律与政策可能修订，具体案件请以最新法律法规、司法解释及专业意见为准。
