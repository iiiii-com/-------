§1 先立三张地图 Three Maps

学法第一步不是背条文，而是先有"骨架"。这套图谱的开篇（总览）给了三张地图，复习一遍：

① 效力地图

宪法 > 法律 > 行政法规 > 地方性法规 > 规章。任何规定先问"它出自哪一层"。

② 部门地图

七大部门法：宪法相关法 / 民法商法 / 行政法 / 经济法 / 社会法 / 刑法 / 程序法。

③ 分类坐标

公法 vs 私法；实体法 vs 程序法。任何规则都能定位到这两个坐标。

有了地图，再遇到新法条

你会自动问：它属于哪个部门？效力多高？是管公家还是私人？是定权利还是定打法？——这一步能让你不迷路。

·

·

后果法律效果：权利/义务/处罚

例：民法典第584条 → 主体（当事人）× 行为（违约）× 条件（造成损失）× 后果（赔偿，以可预见为限）。

法条里的关键词怎么理解
"应当" vs "可以""应当"＝强制义务（必须）；"可以"＝授权（可选择）
"但书"（但是……）前面的例外条款，往往比正文更重要（如"但是……的除外"）
"依照……的规定""适用……"援引条款，需要跳转去看被援引的那条
"本法/本条例下列用语的含义"定义条款，先在开头（总则/附则）找定义，避免望文生义
"以上/以下"法律中一般含本数（有特别说明除外）

§3 法律解释方法 Interpretation

法条有歧义时，靠一套公认的解释方法。掌握它，你就能像法律人一样推理。

方法核心问题举例（思路）
文义解释文字通常含义是什么？从用语在日常/法律中的通常意义出发
体系解释它在整部法里处于什么位置？联系前后条、相关章，保持一致性
目的解释这条要保护什么、解决什么？按立法目的（如保护弱者、维护交易安全）取义
历史解释立法/修订时想改变什么？对比新旧版本、修法说明
当然 / 反对解释举重明轻、举轻明重；反面推论"禁止重罚"→ 轻的行为更不应重罚
顺序

一般先文义，再体系、目的、历史；文义解释不能突破法律条文的可能含义（不能"司法造法"）。

§5 高效学习路径 Path

普通人为己所用

按"用得上的先后"学：劳动 → 消费 → 交通治安 → 婚姻继承 → 网络。每学一条问自己"我怎么用、怎么防"。

体系化 / 备考

宪法 → 民法 → 刑法 → 行政法 → 程序法。用一部体系教材 + 本法典逐条对照。

案例倒推法

先看一个真实案例（判决书），再倒推它用到哪些法条、怎么论证。比死记条文快得多，也更接近实战。

三个学习习惯

① 费曼：把一条法条用大白话讲给别人（本图谱每张卡片的"大白话"就是这个思路）；② 建卡片：一张卡片＝一条法条（原文 + 场景 + 误区 + 官方链接）；③ 间隔重复：高频条文（时效、赔偿、期限）定期回顾。

§6 法系与法理学常识 Legal Systems & Theory

读法条之前，先懂三个"底层设定"：我们属于哪种法系、法条按什么位阶排、一条规范由什么构成。懂了这些，几万条法条才有共同的语法。

① 大陆法系（成文法）

以法典化的成文法为主要渊源，法官依条文裁判。法国、德国、日本及中国属之。特点是体系严谨、条文优先，判例不具正式拘束力。

② 英美法系（判例法）

以判例为主要渊源，遵循"先例"（stare decisis）。英国、美国属之。中国不属此系，但最高法指导性案例要求"应当参照"，起事实上的指引作用。

立法法 98 / 99 / 100

法的位阶：宪法最高，法律高于法规、规章

宪法相关法 · 立法权限与效力
第98条　宪法具有最高的法律效力，一切法律、行政法规、地方性法规、自治条例和单行条例、规章都不得同宪法相抵触。
第99条　法律的效力高于行政法规、地方性法规、规章。行政法规的效力高于地方性法规、规章。
第100条　地方性法规的效力高于本级和下级地方政府规章。省、自治区的人民政府制定的规章的效力高于本行政区域内的设区的市、自治州的人民政府制定的规章。
大白话　法条效力从高到低：宪法 > 法律 > 行政法规 > 地方性法规 > 规章。遇到"两份规定打架"，先看谁的位阶高——下位法与上位法抵触的部分无效。
生活场景　某地方规章设定的赔偿标准"低于"一部法律的强制标准 → 应以法律为准；看到"某条例 / 某办法"，先问一句：它是法律、行政法规，还是规章？
常见误区　①司法解释不是"法律"，但它对审判有拘束力，与所解释的法律一并适用；②部门规章之间、部门规章与地方政府规章之间具有同等效力（第102条），谁也压不过谁；③"特别规定 vs 一般规定""新规定 vs 旧规定"的规则见 §7。
民法典 1 / 2 / 10

民法管什么：平等主体的人身与财产关系

民法商法 · 调整对象与法源
第2条　民法调整平等主体的自然人、法人和非法人组织之间的人身关系和财产关系。
第10条　处理民事纠纷，应当依照法律；法律没有规定的，可以适用习惯，但是不得违背公序良俗。
第1条　为了保护民事主体的合法权益，调整民事关系，维护社会和经济秩序，适应中国特色社会主义发展要求，弘扬社会主义核心价值观，根据宪法，制定本法。
大白话　"平等主体"是民法与行政法、刑法的分水岭：你和商家、你和公司之间地位平等，归民法管；公安罚你、检察院起诉你，是"官对民"，归行政法、刑法管。民法的法源顺序是：法律 → 习惯（且不违背公序良俗）。
生活场景　与邻居的相邻纠纷，法律无细规定时，多年形成的通行、采光等惯例，在不违背公序良俗的前提下可参照，这正是第10条"可以适用习惯"。
常见误区　①民法典不调整"官民关系"，也不规定犯罪与刑罚；②"习惯"不是随便的惯例，须法律无规定、且不违背公序良俗时才用；③宪法是根本法，一般不当庭直接裁判民事案件，而是通过各部门法落地。
一条规范的"三要素"

任何一条规范通常由三块构成：假定条件（在什么情形下适用）＋行为模式（可以 / 应当 / 禁止做什么）＋法律后果（奖励或制裁）。本页 §2 的"四要素拆解"，就是把这三块落到"主体—行为—条件—后果"上。

立法法 103 / 104 · 民法典 11

规定打架怎么办：三条冲突规则

宪法相关法 · 民法商法 · 法律适用规则
立法法第103条　同一机关制定的法律、行政法规、地方性法规、自治条例和单行条例、规章，特别规定与一般规定不一致的，适用特别规定；新的规定与旧的规定不一致的，适用新的规定。
立法法第104条　法律、行政法规、地方性法规、自治条例和单行条例、规章不溯及既往，但为了更好地保护公民、法人和其他组织的权利和利益而作的特别规定除外。
民法典第11条　其他法律对民事关系有特别规定的，依照其规定。
大白话　记三句话：①上位法优于下位法（看位阶）；②特别法优于一般法（看是否"专门管这件事"）；③新法优于旧法（看时间）。后两条以"同一机关制定"为前提。
生活场景　同样是网购纠纷，消保法是一般法，电子商务法是专门的特别法；二者不一致（均属同一机关制定的法律）时，优先适用特别规定。
常见误区　①三条规则不是随意排序：先看位阶，同一位阶才比"特别/一般""新/旧"；②"新的一般规定"与"旧的特别规定"冲突不能确定时，依第105条由全国人大常委会裁决；③法律原则上不溯及既往，不能用新法判旧事。
关键词检索三板斧
  • 法律名 + 条文号：如"劳动合同法 第47条"，最直接。
  • 争议焦点词：如"二倍工资""竞业限制""医疗期"，用来找条文。
  • 案由 + 关键词：如"劳动争议 加班费"，在裁判文书网找同类判决。
查不到时：走备案审查

立法法第110条：公民认为行政法规、地方性法规、自治条例和单行条例同宪法或者法律相抵触的，可以向全国人大常委会书面提出审查建议，由常委会工作机构审查。第112条规定了后续处理程序。这是"下位法违法时"的救济出口。

三类最容易踩的坑
  • 把"修订前的旧文"当现行法：务必核对"施行日期"与版本（本图谱每页 §附录 都标了公布 / 施行日期）。
  • 把"草案 / 征求意见稿"当生效法条：草案不生效，只能作为立法动向参考。
  • 把"解读文章"当法条原文：二次加工常有删改，回到 flk.npc.gov.cn 核对原文。

§8 法律责任的四类归位 Four Kinds of Liability

同一个行为可能同时引发好几重责任。先判断"该进哪个门"，再找对应法：民事赔偿、行政处罚、刑事责任、国家赔偿。

责任类型谁对谁典型后果主要法律
民事责任平等主体之间赔偿损失、恢复原状、赔礼道歉等民法典
行政责任行政机关 → 公民 / 组织警告、罚款、吊销许可证件、行政拘留行政处罚法、治安管理处罚法
刑事责任国家 → 犯罪人管制、拘役、有期徒刑、无期徒刑、死刑；罚金等刑法
国家赔偿国家 → 受害人违法行使职权造成损害，由国家赔偿国家赔偿法
民法典 179

民事责任的方式：不止"赔钱"一种

民法商法 · 承担民事责任的方式
第179条　承担民事责任的方式主要有：（一）停止侵害；（二）排除妨碍；（三）消除危险；（四）返还财产；（五）恢复原状；（六）修理、重作、更换；（七）继续履行；（八）赔偿损失；（九）支付违约金；（十）消除影响、恢复名誉；（十一）赔礼道歉。……本条规定的承担民事责任的方式，可以单独适用，也可以合并适用。
大白话　民事责任不是只有"赔钱"：停止侵害、消除影响、赔礼道歉都算，而且可以叠加使用。写诉讼请求时，一次主张多种完全合法。
生活场景　名誉权被侵害，起诉时可同时请求：停止侵害 + 消除影响、恢复名誉 + 赔礼道歉 + 赔偿损失——这正是"合并适用"。
常见误区　①"赔礼道歉"是独立的民事责任方式，不只是道德要求；②民事赔偿与行政罚款、刑事罚金性质不同，可以并行；③惩罚性赔偿只在法律明确规定时适用。
行政处罚的种类（行政处罚法 9）

第9条列举六类：警告、通报批评；罚款、没收违法所得、没收非法财物；暂扣许可证件、降低资质等级、吊销许可证件；限制开展生产经营活动、责令停产停业、责令关闭、限制从业；行政拘留；法律、行政法规规定的其他行政处罚。注意：限制人身自由的处罚只能由法律设定。

刑罚：主刑 + 附加刑（刑法 33 / 34）

第33条主刑：管制、拘役、有期徒刑、无期徒刑、死刑。第34条附加刑：罚金、剥夺政治权利、没收财产；附加刑也可以独立适用。

民事诉讼法 123 / 124

民事起诉状：法定必备四项

程序法 · 起诉与受理
第123条　起诉应当向人民法院递交起诉状，并按照被告人数提出副本。书写起诉状确有困难的，可以口头起诉，由人民法院记入笔录……
第124条　起诉状应当记明下列事项：（一）原告的姓名、性别、年龄、民族、职业、工作单位、住所、联系方式……（二）被告的姓名、性别、工作单位、住所等信息……（三）诉讼请求和所根据的事实与理由；（四）证据和证据来源，证人姓名和住所。
大白话　起诉状就是把四块写清：谁告谁 ＋ 要什么 ＋ 为什么 ＋ 有什么证据。写不动可以口头起诉，由法院记笔录。
生活场景　追讨借款：原告信息 → 请求"判令被告返还借款本金 X 元及利息" → 事实理由写"借款时间、金额、到期未还"，依据民法典第667条、第675条 → 附借条、转账记录作为证据。
常见误区　①"诉讼请求"要具体、可执行，别只写"依法处理"；②要按被告人数提交副本；③事实与理由要和证据对得上，只堆法条没有事实赢不了。
民事诉讼法 128 · 调解仲裁法 28

答辩状与劳动仲裁申请书

程序法 · 应诉与劳动仲裁
民诉法第128条　人民法院应当在立案之日起五日内将起诉状副本发送被告，被告应当在收到之日起十五日内提出答辩状。答辩状应当记明被告的姓名、性别、年龄、民族、职业、工作单位、住所、联系方式；法人或者其他组织的名称、住所和法定代表人或者主要负责人的姓名、职务、联系方式……
调解仲裁法第28条　申请人申请仲裁应当提交书面仲裁申请，并按照被申请人人数提交副本。仲裁申请书应当载明下列事项：（一）劳动者的姓名、性别、年龄、职业、工作单位和住所，用人单位的名称、住所和法定代表人或者主要负责人的姓名、职务；（二）仲裁请求和所根据的事实、理由；（三）证据和证据来源、证人姓名和住所。书写仲裁申请确有困难的，可以口头申请……
大白话　答辩状是"被告的回应"，收到起诉状后15 天内提交（不提交不影响审理，但会失去先手）。劳动仲裁申请书和起诉状结构一样，也是当事人 + 请求 + 事实理由 + 证据，只是受理机关换成"劳动人事争议仲裁委员会"。
生活场景　被公司拖欠工资去仲裁：申请人（你）＋ 被申请人（公司全称、法定代表人）＋ 仲裁请求（支付工资 X 元、经济补偿 Y 元）＋ 事实理由（在职时间、欠薪经过）＋ 证据（劳动合同、工资流水、考勤）。对裁决不服，可在收到裁决书 15 日内起诉。
常见误区　①仲裁申请要按被申请人人数提交副本；②"用人单位全称"要写营业执照上的准确名称，写错可能不予受理；③书写确有困难的可口头申请，由仲裁委记入笔录。

§10 法考与自学路线 Exams & Self-study

"为己所用"和"备考职业资格"路线不同、取舍不同。这里给两条清晰路径和一张资源清单。

普通自学 · 够用就好

目标：遇到事能"看懂、表态、找对人"。路线：劳动 → 消费 → 交通治安 → 婚姻继承 → 网络。每块掌握 5～10 个高频条文（时效、赔偿、期限）即可上手。

法考 / 体系化

目标：通过国家统一法律职业资格考试。先搭体系（宪法 → 民法 → 刑法 → 行政法与行政诉讼法 → 三大诉讼法，再补商经、法理），再训练"要件—法条—结论"的答题链条。

法考两阶段

国家统一法律职业资格考试分客观题与主观题两阶段：先过客观题（以选择题为主），再考主观题（案例分析、法律文书、论述等）。通常客观题成绩合格方可参加当年主观题。具体报名、考试时间与科目以当年司法部公告为准。

阶段主线任务方法
打地基搭部门法体系，理解概念（主体 / 行为 / 责任）读一册体系教材，配 §1 三张地图建立坐标
过法条核心单行法逐条过一遍，标出"要件词"用 §2 四要素拆解法做"法条卡片"
做真题以题带点，暴露盲区错题回扣法条原文，用 §7 检索实操核对
练文书主观题：案例、文书、论述按 §9 骨架写起诉状 / 答辩状 / 代理意见
免费法律帮助，别忘用

法律援助法第31条：请求确认劳动关系或者支付劳动报酬、请求给予社会保险待遇、请求工伤事故人身损害赔偿等事项，因经济困难没有委托代理人的，可以向法律援助机构申请法律援助；第32条还规定见义勇为、遭受家暴等情形不受经济困难条件限制。遇到难事，12348 公共法律服务热线也是入口。

§11 核验与避坑 Verify

四条铁律
  • 认准官方来源：法条以"国家法律法规数据库"为准；网络转载、旧帖子常有过时或错误。
  • 先看施行日期：同一部法可能已修订。例：《治安管理处罚法》2026-01-01 起施行的新版，罚款标准已上调。
  • 区分"法律"与"观点"：自媒体解读 ≠ 法律规定；司法解释、指导性案例有特殊效力。
  • 交叉验证：关键结论至少核对"法条原文 + 官方解释 + 一个真实案例"。
